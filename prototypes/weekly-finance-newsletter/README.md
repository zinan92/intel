# Weekly Finance Newsletter Prototype

Question: can seven Daily Finance Newsletters plus no-key calendar sources produce a useful one-page weekly trader brief?

This branch is a throwaway primary source for Issue #8. It is not the production scheduler.

## Prototype Contract

- Lookback: seven available daily briefs ending Sunday morning.
- Watch window: the following Monday through Sunday.
- Discovery: Nasdaq economic-events and earnings endpoints.
- Verification: official BEA and Federal Reserve calendars for the highest-impact US events.
- Delivery during evaluation: Obsidian and one Feishu send.
- Deferred until Park approves the content: launchd schedule, public website route, database model, and production collectors.
